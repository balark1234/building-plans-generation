# 🏗️ Building Plans Generation

AI-powered building plans generation project

## Overview

This project creates an intelligent system that turns site details and user building vision into compliant architectural plans using LLM self-correction and matplotlib visualization.

## Key Features

- Rich input: site details + building vision (stories, type, layout, elevation)
- Automatic zoning law compliance
- LLM self-correction loop
- Matplotlib 2D plans + optional image generation

## How It Works

1. Input Collection (Site + Building Vision/Mind Map)
2. Zoning Law Retrieval
3. LLM Plan Generation + Self-Correction Loop
4. Visualization with Matplotlib
